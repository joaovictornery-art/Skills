# Como é que é?

## Quickstart

```bash
npx skills@latest add joaovictornery-art/Skills --skill=como-e-que-e
```

[Source](../../skills/productivity/como-e-que-e)

## What it does

`como-e-que-e` asks Codex to stop and re-pitch the previous answer in clear
Brazilian Portuguese. It is for moments when the last response did not land:
it missed the point, skipped needed context, leaned on jargon, or answered in
English. When a concept is abstract or hard to visualize, it can add a short
analogy or concrete example while keeping the literal explanation primary.

## When to reach for it

Invoke `$como-e-que-e` manually right after an unclear answer. The skill keeps
the same technical identifiers, commands, paths, and project terms, but rebuilds
the explanation from scratch with simpler phrasing.

Analogies are used selectively. They support the definition rather than replace
precision for numbers, rules, commands, identifiers, or other technical details.

It is deliberately user-invoked because only the reader can reliably know when
the previous answer did not make sense.
